# Highline Ridge
Highline Ridge is the working title for this point and click mystery game.  At this point my storyboarding has hit a brick wall and I am primarily focused on developing the engine.  Eventually I would like to finish a simple game to showcase the engine.  Contributions are always welcome

## Build Instructions
The only third party dependancy is Raylib which cmake should pull down for you.  You will need a c/c++ compiler and a python interpreter.  This build has only been tested on MacOs(intel).

```bash
mkdir build
cd build
cmake ..
make
cd ../tools/scene-editor
mkdir build
cd build
cmake ..
make
```

## About the Engine
- No name yet.  Designed to be a rich story telling platform while using old-school fixed images to allow one developer, with the help of AI to generate scenes.
- Uses text to speech aided by grok voices.  Every dialog has a default voice and markup that allows you to switch from a narrator voice to an actor voice.  Audio is a static compressed recording that will need to be regenerated by grok after changing.  The Functionality is build into the main game.  You will need to supply your own API key to update voices. The engine uses SHA sums to look for changes in dialog, so dialog which has already been generated and remains the same will not be re-generated.  You can also regenerate specific scenes only. In the console, type "./Highline\ Ridge --help" for more info.
- The resources directory contains all images, audio files and json based conversations and scene configurations.  Binaries are compressed with an xz format.  Currently resources are accessed dynamically which is convenient for development because I don't always need to re-compile, but it means the resources would need to be delivered with the binary.  At a future date I may re-design resources to compile into the binary.
- The Scene-editor located in tools is very much in beta but it does allow much easier manipulation of the scenes.  There is still a lot to go, and many features remain untested
- The engine implements character stats which are designed to change regularly with interactions.  Current stats are:
    - Health:  Quite literally your health.  At 0%, you die (Big surprise). Increases with sleep
    - Energy:  Leads into your ability to stay awake and conduct rigerous tasks, Increases with sleep
    - Resolve:  Also, a factor of rigerous tasks.  Increases with stimulants or booze
    - Lucidity:  In a nutshell, your grip on reality.  Increases with sleep and helps with conversations and intellectual tasks.
    - Charisma:  Also improves odds in conversation.

## The Game
- The year is roughly 1891.  You wake up in a cave, injured and with total memory loss.  You find yourself High in the mountains of appalachia, A couple thousand feet abobe a small mountain town known as "Highline Ridge"  As you move around the town and interact with patrons, you start to get the sense that they know you.  At least some of them do, but they are not readily giving up information.  At lease not straightforward answers.
